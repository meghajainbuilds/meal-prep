# meal-prep

Single-user meal-planning web app for Megha. Weekly plans (Mon-Sun, Seattle), ingredients, prep sessions, recipe library, and actual-eating logs. Owner-only edit; public read-only view of planned content.

Built with the build-it-yourself-harness: foundation + publish + models + always-on.

## Stack
- Hosting: Netlify
- Auth + DB: Supabase (Google sign-in for owner)
- AI: Anthropic Claude
- Always-on: Mac
